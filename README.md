# CARTIFY - Full Stack Ecommerce Platform

Cartify is a modern full stack ecommerce web application built using the MERN stack.  
It includes a customer frontend, admin dashboard, authentication system, wishlist, cart management, order tracking, and responsive premium UI.

---

## 🚀 Features

### User Features
- User Authentication
- Product Collections
- Product Search
- Add to Cart
- Wishlist Functionality
- Place Orders
- Responsive Design
- Product Details Page
- Order History

### Admin Features
- Admin Dashboard
- Add Products
- Delete Products
- Manage Orders
- Update Order Status
- Product Listing Management
